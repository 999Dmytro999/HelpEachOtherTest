# HelpEachOther

HelpEachOther is a web application built with .NET where people in need can create posts describing what help they need, and other people can help them and earn soul points.

## Tech Stack
- .NET
- ASP.NET Core Razor Pages
- C#
- JetBrains Rider

## Project Goal
The goal of this project is to create a simple platform that helps people support each other.
